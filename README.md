# My Vibe Coding Journey

### Learning, Building, Experimenting, and Growing with AI

Welcome to my Vibe Coding Journey!

This repository documents my journey of learning, experimenting, and building software applications with AI-assisted development tools.

Through Vibe Code Tours Cohort 1, Claude 101, and Claude Code 101, I explored how AI can transform the way we approach software development.

This book shares my experiences, projects, challenges, lessons learned, and future goals.

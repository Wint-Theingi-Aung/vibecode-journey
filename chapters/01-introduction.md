# My Vibe Coding Journey 🚀

### From Learning to Building with AI

---

## Introduction

I wanted to create my own project when vibe coding started becoming popular. However, I didn't really understand AI workflows, how to get started, how to use AI coding tools, or what features and specifications to include in a project.

Although I had already tried building my very first vibe coding project, called **[ubuntu-localization](https://github.com/Wint-Theingi-Aung/ubuntu-localization)**, it was only an initial version or beta version. At that time, I had a project idea in mind, but I didn't know how to design the UI or implement additional features. It wasn't publicly deployed either; it only ran locally at `localhost:3000`. It was far from what I had envisioned.

Then, I came across some exciting news about **Vibe Code Tours** from someone I admire, **Ko Ko Ye**, on Facebook. The program aimed to teach us how to use **Claude Code, MCP, Skills, Agents**, and other AI development tools.

At that point, I had heard those terms but barely understood what they meant, how to use them, or where to configure them. What caught my attention most was the main idea behind the program: understanding AI workflows and learning how to turn an idea into a fully developed, deployment-ready product using AI.

As soon as I heard about the program, I decided to join the tour. My goal was to upgrade my first project, improve my AI-assisted development skills, and take my project to the next level.

> **From having just an idea to building and deploying a real product — this is where my journey begins.**
